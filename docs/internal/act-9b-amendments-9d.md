## 2. Поправки к акту (решения архитектора, в силе для `stage9`)

- **A-1 (R3, результат плитки).**
  - Свежий проверенный результат переживает `SetDeselected` и `UnAdvise`. Он по-прежнему живёт не больше 10 с и используется один раз.
  - Стирается при `ReportResult`, по TTL, при старте нового скана, в деструкторе и при защёлке `m_scansDisabled`.
  - `HasResult` = свежий и не заблокирован; выбранность плитки больше не требуется.
  - Причина: порядок вызовов LogonUI вокруг `CredentialsChanged` не документирован. Живьём (7-i) доказана семантика, где результат это переживает. Со стиранием автологон может никогда не завершиться и сканировать по кругу.
- **A-2 (§2.1, отчёт о гранте).**
  - `report_result` отправляется синхронно внутри `ReportResult`, общий потолок 750 мс: connect, проверка доверия, запись; ответ ждём только в остатке времени.
  - Отсоединённый поток-репортёр убрать. Причина: после успешной разблокировки LogonUI.exe завершается и может убить поток до отправки.
  - Сервис фиксирует грант сразу после разбора запроса — до записи ответа. Неудачная запись ответа фиксацию не отменяет.
- **A-3 (R4, неподвижность и базы шагов).**
  - Окно неподвижности `STILLNESS_WINDOW_S` отсчитывается от **первой поданной позы с совпадением личности**, а не от первого кадра камеры.
  - В окне должно быть не меньше 2 поз, и все межкадровые |Δyaw|, |Δpitch| ≤ `STILLNESS_MAX_DEG`. Меньше 2 поз — окно начинается заново со следующей позы. Движение — `motion-before-prompt`.
  - Шаги засчитываются только после выполненного окна.
  - Для пары противоположных поворотов (left→right, right→left) цель второго шага считается от **нейтральной позы окна**, то есть нужен переход через центр на `YAW_DELTA` в другую сторону. Для пар с кивком базы шагов прежние.
  - Константы не меняются.
- **A-4 (R10, аренда мастера).** Мастер держит аренду камеры, пока держит устройство: превью, съёмка, сборка, калибровка. Без аренды камера в мастере не открывается.
- **A-5 (R14, тосты).**
  - WinRT нативно через pywinrt (MIT): `winrt-runtime`, `winrt-Windows.UI.Notifications`, `winrt-Windows.Data.Xml.Dom` и `winrt-Windows.Foundation`, если нужен.
  - Ни один exe продукта во время работы не запускает `powershell.exe`.
- **A-6 (R18, варианты).**
  - CPU-вариант собирается из пакета `onnxruntime` (CPU) в отдельном venv, GPU — из `onnxruntime-gpu`.
  - GPU-установка по локу: `--require-hashes --no-deps` плюс проверка полноты. insightface требует `onnxruntime`; его покрывает `onnxruntime-gpu`.
- **A-7 (R5, темнота в фазе 2).**
  - Провал фазы 2 при `scene_luma` None или ниже `low_light_luma_min` даёт `too-dark` без страйка.
  - Буст в фазе 2 не добавляем: решение по замерам 9e (сумерки).
- **A-8 (§2.1).** Путь `no-credentials` lockout не сбрасывает и страйка не даёт. Сброс — только по `report_result ok=true`.
- **A-9 (продукт, Quit).**
  - «Выйти» выключает вход по лицу и блокировку при уходе до следующего входа в Windows или до запуска Face Unlock из «Пуска».
  - Реализация — пауза, привязанная к сеансу входа (без TTL). Watchdog её уважает; старт трея её снимает.
